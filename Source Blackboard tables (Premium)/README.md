The queries contained in this folder can be used by customers with a Premium license to query the raw Blackboard Learn tables in Illuminate.

## AI Conversations

The [ai-conversations](ai-conversations/) folder contains queries for extracting and analyzing AI conversation data from Blackboard Learn. AI Conversations (AI Chat questions) are interactive assessments where students engage with AI-powered chatbots configured with specific roles and personas. 

The folder includes queries covering:
- Complete conversation transcripts between students and AI bots
- AI assessment structure and metadata
- Student reflection responses
- Conversation analytics (message counts, engagement metrics)
- Question prompts and key learning points

See the [ai-conversations README](ai-conversations/README.md) for detailed documentation on data structure, available queries, and common patterns for working with AI conversation data.
