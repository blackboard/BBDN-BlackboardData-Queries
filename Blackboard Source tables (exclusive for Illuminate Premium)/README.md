The queries contained in this folder can be used by customers with a Premium license to query the raw Blackboard Learn tables in Illuminate.

## AI Conversations

The [ai-conversations-usage-source-tables](ai-conversations-usage-source-tables/) folder contains queries for extracting and analyzing AI conversation data from Blackboard Learn. AI Conversations are interactive activities where students engage with AI-powered chatbots configured with specific roles and personas.

The folder includes example queries covering:
- Complete conversation transcripts between students and AI bots
- AI assessment structure and metadata
- Student reflection responses
- Conversation analytics (message counts, engagement metrics)
- Question prompts and key learning points

See the [ai-conversations-usage-source-tables README](ai-conversations-usage-source-tables/README.md) for detailed documentation on data structure, available queries, and common patterns for working with AI conversation data.
